# 🍕 KAFE — Лендинг семейного кафе «РОКНРОЛЛЫ»

Адаптивный лендинг для мультиформатного заведения **«РОКНРОЛЛЫ»**, сочетающего паназиатские рецепты, классику японской кухни и европейские хиты. Проект включает презентацию концепции кафе, блок «Мы в цифрах», видео-презентацию атмосферы и интерактивные слайдеры с меню.

🔗 **Демо-версия (GitHub Pages)**: [https://tiafk.github.io/kafe/](https://tiafk.github.io/kafe/)  
🌐 **Оригинальный сайт **: [rocknrolls.ru]([https://rocknrolls.ru/](https://rocknrolly.ru/about))

## ✨ Особенности проекта

- **Модульная архитектура стилей**: использование SCSS/SASS с разделением кода на логические блоки для упрощения поддержки, чтения и масштабирования проекта.
- **Полностью адаптивная и кроссбраузерная вёрстка**: корректное и пиксель-перфект отображение на десктопных, планшетных и мобильных устройствах.
- **Работа с мультимедиа**: интеграция фоновых и контентных видео с атрибутами `autoplay`, `muted`, `loop` и `playsinline` для корректной работы на мобильных устройствах.
- **Интерактивные слайдеры**: использование библиотеки **Swiper.js** для создания адаптивных каруселей блюд и сезонного меню с кастомной навигацией.
- **Внимание к деталям**: использование кастомных SVG-элементов (декоративные линии, иконки) и сложных схем позиционирования для создания уникального визуального стиля.
- **Оптимизация**: ленивая загрузка ресурсов, чистый и семантический HTML5, проверка стилей на конфликты через консоль разработчика.

## 🛠️ Используемые технологии

- **HTML5** (семантическая разметка, работа с видео и SVG)
- **SCSS / SASS** (препроцессор для организации и компиляции стилей)
- **CSS3** (Flexbox, Grid, анимации, медиа-запросы)
- **JavaScript (Vanilla JS)** (инициализация и настройка слайдеров Swiper, управление видео)
- **Swiper.js** (современная библиотека для создания тач-слайдеров)
